# Sketchnote portfolio rebuild

Static preview of `rizkal.wtf` rebuilt with the line-art portrait art direction.

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8080 --directory sketchnote
```

Preview images are in `preview/`. This is an isolated branch preview; the Astro site on `main` is untouched.
